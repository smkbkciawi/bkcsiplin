Apa itu BKCSiplin?

Definisi

BKCSiplin adalah sistem informasi berbasis web yang mengintegrasikan seluruh proses administrasi kedisiplinan dan kehadiran di SMK Bhakti Kencana Ciawi dalam satu platform terpadu.

Nama BKCSiplin berasal dari singkatan BKC (Bhakti Kencana Ciawi) + Disiplin.

TujuanMenghilangkan proses manual, mengurangi beban administrasi, dan menghadirkan data yang akurat dan real-time untuk pengambilan keputusan.

7 Fungsi Utama

Presensi Gerbang — kehadiran masuk & pulang siswa
Presensi Sholat — 5 waktu sholat berjamaah
Kedisiplinan — poin pelanggaran & prestasi
Presensi Guru — masuk, pulang, jam kerja
Keterangan Absen — izin, sakit, alpa
Raport Digital — otomatis per periode
Laporan — real-time ke pimpinan
Bagian 1 · Pembukaan

Mengapa Perlu Sistem Ini?

Masalah Sebelumnya

Presensi manual kertas → mudah hilang, susah dilacak
Rekap kehadiran → memakan waktu berjam-jam
Laporan ke Kepsek → lambat, tidak real-time
Poin pelanggaran → susah dihitung, rawan konflik
Presensi sholat → tidak terdokumentasi rapi
Orang tua → tidak tahu kehadiran anak
Wali kelas → sulit pantau kelasnya
Data antar unit → tidak terhubung

Solusi dengan BKCSiplin

Presensi gerbang scan QR/RFID — otomatis tercatat
Rekap kehadiran instan <5 detik — real-time
Laporan ke Kepsek real-time — langsung tersedia
Poin pelanggaran otomatis tersaldo — akurat
Presensi sholat terdokumentasi rapi — 5 waktu
Orang tua pantau mandiri — via portal publik
Wali kelas dashboard khusus — kelas sendiri
Semua data terintegrasi — satu sistem

Bagian 3 · Arsitektur

Keamanan Data Berlapis

1. Login 2 Faktor

ID Guru + PIN · verifikasi role & modul yang diakses

2. Token Session

Berlaku 30 menit · Auto-logout idle 10 menit · Heartbeat 2 menit

3. Role-Based Access

6 role berbeda · Hak akses ketat per modul · Verifikasi di backend

4. Audit Trail

Setiap aksi penting tercatat · Siapa, kapan, apa yang dilakukan

5. Backup Otomatis

Google Spreadsheet backup · Bisa restore dari histori

6. HTTPS

Semua komunikasi terenkripsi · GitHub Pages sertifikat SSL

Portal Sholat — Presensi Ibadah

smkbkciawi.github.io/bkcsiplin/sholat.html
Buka ↗

Fungsi

Presensi sholat 5 waktu + manajemen udzur syar'i + laporan.

Cara Kerja

  1. Pilih waktu sholat (5 pilihan)
  2. Scan kartu / cari nama
  3. Sistem catat dengan timestamp
  4. Suara beep = sukses, tetot = gagal

✓ Print/PDF siap tanda tangan

Cara Menggunakan Presentasi Ini

Keyboard Shortcut

→ / Space — Slide berikutnya
← — Slide sebelumnya
F — Fullscreen
O — Overview (semua slide)
Home — Slide pertama
End — Slide terakhir
Esc — Keluar fullscreen / tutup overview

Simpan sebagai PDF

  1. Tekan Ctrl+P (atau Cmd+P)
  2. Pilih "Save as PDF"
  3. Orientation: Landscape
  4. Save
Catatan: iframe live tidak akan tersimpan di PDF — hanya slide teks. Untuk PDF dengan screenshot, lihat tab berikut.

Saat Presentasi

✓ Buka file `presentasi.html` di browser
✓ Tekan F untuk fullscreen
✓ Navigasi dengan →
✓ Klik area iframe untuk interaksi langsung
✓ Tekan O untuk lompat ke slide tertentu

Tips

• Test koneksi internet sebelum presentasi
• Login dulu di portal yang butuh auth
• Siapkan backup: PDF (tanpa iframe)
• Jika iframe tidak load → buka tab baru manual
